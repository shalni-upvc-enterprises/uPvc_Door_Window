SHALNI ALUMINIUM HOUSE - ADMIN VERSION

Customer website:
- index.html
- Customers only select products, enter size/quantity and send enquiry on WhatsApp.
- Customers do NOT see rates on product cards.

Admin:
- admin.html
- Owner can edit business name, WhatsApp number, address, hero text.
- Owner can edit every product name, category, description, rate (₹/sq.ft.) and photo.
- Default catalogue contains 61 products covering uPVC, Aluminium and related work.
- Default admin password: 1234. Change it in Admin Panel.

IMPORTANT:
This is a static/free GitHub Pages version. The admin data is stored in the browser's localStorage.
Therefore changes are shared only on the same browser/device; they are NOT automatically stored on the public server for all customers.

For a TRUE online admin panel where you change a rate/photo/text on your phone and every customer immediately sees it, the next version should connect this same design to a free cloud database/storage (e.g. Firebase or Supabase) with owner authentication. Do not put a secret API key or GitHub token in browser code.

GitHub Pages:
Upload all files/folders to the repository root and enable Settings -> Pages -> Deploy from branch -> main -> /(root).

Logo: supplied shop logo is included as images/shop-logo.png and can be replaced from Admin Panel.
Admin can edit shop name, call number, WhatsApp/enquiry number, logo, hero text and all product details/rates/photos.
